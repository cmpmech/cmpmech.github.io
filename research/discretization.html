Key works

GPU-accelerated simulation

Graphics cards accelerate highly parallel, repetitive computations, which numerical simulations can exploit for much shorter runtimes. cuwave is a differentiable finite difference code for wave propagation on a single GPU, and mlhp can run parts of its finite element pipeline (matrix-free assembly and iterative solvers) on the GPU.
