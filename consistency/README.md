# Consistency

Shared settings for the figures and videos on the website, so that media produced
in other repositories (e.g. `neuralmech/code/projects/0_website`) look alike.

- `rainbow_desaturated.cmap`: ParaView's "Rainbow Desaturated" colour map (JSON),
  used for every field plot. Load it with `postprocessing.load_cmap` from neuralmech.
